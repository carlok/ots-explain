# Code of conduct

Be kind and be specific. Disagree with the code, the spec or the argument, not with the person. No harassment,
no discrimination, no publishing other people's private information. Maintainers may edit, hide or remove
contributions and may block people who do not follow this.

Report problems to the maintainer on GitHub ([@carlok](https://github.com/carlok)); for security issues use the
private advisory flow in `SECURITY.md`. This short text is the project's
own; if the project grows, adopting the Contributor Covenant would be the natural next step.
