Did this file exist before a Bitcoin block?

An OpenTimestamps proof (.ots) says it did. This page recomputes every hash on the way from your file to the block and shows each one, so you can see the claim hold or break. It can also stamp a file to start a new proof.

Nothing is uploaded. Your file is hashed in this tab, and the page sends nothing until you press a button that says what it will send.

Keep the free calendars running

Stamping is free because volunteers run the public calendar servers and pay the Bitcoin fees. OpenTimestamps says they rely on donations, accepted in bitcoin (some also Lightning). Each calendar's own page shows its wallet address; this page deliberately carries no addresses, so a copy of it can never point you somewhere else. Open the calendar you used and donate from there:

  • alice.btc.calendar.opentimestamps.org
  • bob.btc.calendar.opentimestamps.org
  • finney.calendar.eternitywall.com
  • btc.calendar.catallaxy.com

These links only open the sites; the page sends nothing. Compare the address on the calendar's page with opentimestamps.org before sending, and never send more than you can afford to lose.
