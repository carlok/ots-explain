# Where the test vectors come from

* `vectors/<id>/proof.ots` and `data.bin` for the 21 imported vectors: copied **unmodified** from the example
  folders of `opentimestamps/javascript-opentimestamps` (14), `opentimestamps/opentimestamps-client` (6) and
  `opentimestamps/java-opentimestamps` (1). `vectors/index.json` records, per vector, the repository, the original
  path and the SHA-256 of both files.
* **Licence: LGPL-3.0, read from the three repositories' own files** (`LICENSE` in each; `"license": "LGPL-3.0"` in the
  JavaScript `package.json`; `<license>` in the Java `pom.xml`). None of the three has a separate notice for its
  `examples/` folder, so the imported example files are treated as LGPL-3.0 material. They are kept **unmodified**
  (SHA-256 in `index.json`), the licence text is in `vectors/LICENSE-LGPL-3.0.txt`, and they are test data only:
  they are not part of `dist/index.html`, `python/` or the container's runtime image. The rest of the repository
  stays Apache-2.0. No code from those projects is included. This is a good-faith reading by a non-lawyer; if a
  maintainer objects, delete `vectors/<id>/` for the imported ids and run `tools/make_handcrafted.py`; the tests
  then use the handcrafted vectors only (the conformance test needs both sets, so expect a smaller case count).
* `reference.tree.json` and `reference.info.txt` were produced by running `python-opentimestamps` (as an
  independent check, not copied code) via `tools/reference_dump.py`.
* `vectors/handcrafted/` (24 proofs) was generated by `tools/make_handcrafted.py` in this repository.
* `vectors/explorer/synthetic*` is **synthetic** chain data generated by `tools/make_synthetic_explorer.py`; it is
  not Bitcoin history. Real recordings, once made with `tools/record_explorer.py`, will go under
  `vectors/explorer/recorded-*`.
* `vectors/upgrade/index.json` (7 cases) was generated by `tools/make_upgrade_vectors.py` from the official proofs
  above plus calendar answers written by hand; the expected log lines and bytes come from `python/ots_stamp.py` and
  the TypeScript module must reproduce them (`test/js/upgrade-vectors.test.mjs`).
* `vectors/real/` is **one real stamp**, made by `tools/e2e_real.sh` on 2026-11-08 (file `dummy-2026-11-08.bin`: a line of text with a
  timestamp, nothing private; SHA-256 `fb415de6...2da3`). `.pending.ots` is the proof as the three public calendars returned it
  (alice, bob, finney); `.confirmed.ots` is the same proof after `ots_stamp.py upgrade` got alice's Bitcoin path (block 975064).
  Both are unmodified tool output. Apache-2.0 like the rest of the repository; no third-party material.
* `vectors/wild/` (git-ignored) is where `tools/wild_diff.py` puts proofs it fetches from other people's repositories.
  They are never committed or redistributed: their licences are unknown.
